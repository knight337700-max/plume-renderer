# META M1 source refresh

M1 consumes the official-source registry and audit created in M0:
`contracts/audits/meta-official-source-registry.json`.

No third-party guide, remote font, CDN, or runtime network request is introduced. Officially sourced
ratio semantics are kept distinct from the project-owned 1080-pixel output presets. Stories safe-zone
values are represented as the approved normalized guide (`0.14` top, `0.20` bottom); Reels geometry
remains `SOURCE_REQUIRED` and no coordinates are inferred.
