# External SmartChannel font resources

The four Apple SD Gothic Neo runtime files below are external local resources only. They
are not bundled, committed, published, downloaded at runtime, or redistributed by this
project. Place approved local files under a trusted directory and set
`NAVER_SMARTCHANNEL_FONT_DIR` before SmartChannel runtime checks.

The expected local file names, runtime PostScript aliases, SHA-256 values, and the source
URL are copied from `contracts/naver-smartchannel-runtime-font-policy.json` and
`contracts/naver-smartchannel-font-compatibility.json`. `licenseStatus` is
`NOT_CONFIRMED`; no redistribution claim is made. Exact source identity is not claimed:
the currently approved local resources are `PROJECT_COMPATIBLE_VERIFIED` builds.

N5 `PLATFORM_COMPOSED` text is platform-owned and does not consume these fonts. Kakao
Spoqa assets remain separately governed by `assets/fonts/` and its OFL notice.
